## 画面イメージについて

- `images/*.png` … 画面イメージ（`mockups/*.html` をブラウザで撮影したもの）
- `mockups/` … 画面イメージの元になる HTML。ブラウザで直接開いて確認できる

モックアップを修正したら、PNG を撮り直して差し替えてください（Playwright 等でスクリーンショット）。
