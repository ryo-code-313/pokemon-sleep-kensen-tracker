# 01. 要件定義

## 背景・目的

ポケモンスリープでは、同じポケモンでも **性格** と **サブスキル** の組み合わせで性能が大きく変わるため、
理想の個体を狙って何度も捕まえ直す「厳選」が行われる。

厳選が終わった個体が増えると、次のような困りごとが出てくる。

- どのポケモンをどこまで厳選し終えたか忘れる
- 同じポケモンを2匹以上持っているとき、どちらが良い個体か比較しにくい
- ゲーム内のボックスでは用途（きのみ要員・食材要員など）やメモを残せない

本アプリは **厳選が完了したポケモンを記録・一覧・検索できる** ようにし、育成計画を立てやすくすることを目的とする。

## 対象ユーザー

- ポケモンスリープで厳選を行っているプレイヤー（本人利用を主想定）
- スマートフォンとPCの両方から使う

## スコープ

### やること（MVP）

| No | 機能 | 概要 |
|----|------|------|
| F-01 | 一覧表示 | 登録した厳選ポケモンをカード形式で一覧表示する |
| F-02 | 検索 | ポケモン名・ニックネーム・タグの部分一致で絞り込む |
| F-03 | 絞り込み | とくい（きのみ/食材/スキル）、用途、お気に入りで絞り込む |
| F-04 | 並び替え | 厳選完了日・レベル・ポケモン名・登録日で並び替える |
| F-05 | 登録 | 厳選ポケモンを新規登録する |
| F-06 | 編集 | 登録済みのポケモンの情報を更新する（レベルアップ時など） |
| F-07 | 削除 | 確認ダイアログを経て削除する |
| F-08 | 詳細表示 | 1匹分の全情報を表示する |
| F-09 | エクスポート | 全データをJSONファイルとしてダウンロードする |
| F-10 | インポート | JSONファイルからデータを取り込む（追加 / 全置き換え） |
| F-11 | 全削除 | ブラウザに保存された全データを削除する |

### やらないこと（MVPの対象外）

- ユーザー登録・ログイン、サーバーへのデータ保存（端末間同期）
- ゲーム内データの自動取得（スクリーンショット読み取り等）
- おてつだい量やエナジーの計算・シミュレーション
- 全ポケモンの画像素材の同梱（著作権に配慮し、MVPではプレースホルダー表示）

### 将来の拡張候補

- 厳選「中」の個体や、狙っているサブスキル・性格の「目標」管理
- 同一ポケモン同士の比較画面
- スリープタイプ（うとうと/すやすや/ぐっすり）での絞り込み
- 端末間同期（クラウド保存）
- スクリーンショットからの読み取り補助

## 非機能要件

| 項目 | 要件 |
|------|------|
| 動作環境 | 最新版の Chrome / Safari / Edge（PC・スマートフォン） |
| レスポンシブ | 幅 360px 〜 のスマホから PC まで崩れずに表示できること |
| 保存 | ブラウザの localStorage に保存。オフラインでも閲覧・編集できること |
| 性能 | 500件登録時でも一覧の検索・絞り込みが体感遅延なく動くこと |
| 公開 | GitHub Pages で静的サイトとして公開できること（サーバー不要） |
| データ保全 | データ消失に備え、エクスポートを促す文言を画面に表示すること |
| 権利表記 | 非公式ファンツールである旨をフッター・READMEに明記すること |

## 用語

| 用語 | 説明 |
|------|------|
| 厳選 | 理想の性格・サブスキルを持つ個体を狙って入手し直すこと |
| 性格 | おてつだいスピード等の能力1つを上昇、1つを下降させる。補正なしの性格もある |
| サブスキル | Lv10 / 25 / 50 / 75 / 100 で順に解放される5つの追加能力 |
| とくい | ポケモンのおてつだいの得意分野（きのみ・食材・スキル）。ポケモンの種類で決まる |
| 用途 | ユーザーがその個体をどう使うつもりかの分類（本アプリ独自の管理項目） |
